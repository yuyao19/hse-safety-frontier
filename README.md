# 安全边界 · HSE守护者

面向手机和电脑浏览器的 HSE 动作闯关游戏。玩家可选择马·安禾、猫头鹰·永勋、雪豹·凌曜或边牧·观微，在八类现场中完成危险识别、人员撤离、源头控制、现场保护和复核报告。

## 在线使用与手机安装

仓库启用 GitHub Pages 后，推送到 `main` 分支会自动测试、构建和发布。

- 直接打开 Pages 链接即可游玩。
- Android Chrome 可选择“安装应用”或“添加到主屏幕”。
- iPhone / iPad 使用 Safari 的“分享 → 添加到主屏幕”。
- 微信内置浏览器可以直接游玩；安装时建议选择“在浏览器中打开”。
- PWA 会缓存游戏外壳与主要素材，完成首次加载后可在网络不稳定时再次进入。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

完整检查：

```bash
npm test
```

静态成品输出到 `out/`：

```bash
npm run build
```

## GitHub Pages 发布

1. 在仓库 `Settings → Pages` 中，将来源设为 **GitHub Actions**。
2. 推送代码到 `main` 分支。
3. 等待 `Deploy HSE game to Pages` 工作流完成。
4. 在 Pages 设置或工作流结果中打开公开网址。

工作流会自动识别仓库名称，并处理项目站点的子路径，例如：

`https://yuyao19.github.io/hse-safety-frontier/`

## Android APK

仓库已包含 Capacitor Android 工程。`Build Android APK` 工作流会将静态游戏资源打入应用内部，生成可离线安装的体验签名版 APK。

```bash
CAPACITOR_BUILD=true npm run build
npm run android:sync
cd android
./gradlew assembleDebug
```

体验签名版适合内部试玩和直接转发，不作为应用商店正式发布版本。正式发布前应另行创建并妥善保管 release 签名密钥，且不得将密钥或密码提交到公开仓库。

## 已实现内容

- 四名可选角色及不同主动技能。
- 八类现场、24 个关卡配置和 29 项危险主题图鉴。
- 八套独立地图结构、环境压力机制、动态事件和现场受控后的视觉变化。
- 八套原创程序化自适应声景，随探索、危机和受控状态实时变奏，可完全离线播放。
- 键盘、鼠标、触控摇杆、自动射击、手动射击和任务自动寻路。
- 物资拾取、24 项角色与通用局内升级、三类敌人行为、两阶段首领、连击称号及连续闯关。
- 手机安全区适配、后台自动暂停、本机成绩保存。
- PWA 桌面安装、主要资源缓存和离线回访。
- 无账号系统，不采集姓名、成绩或其他个人信息。

24 个关卡按八类现场组织，每类现场拥有独立空间结构和环境规则；29 项危险主题复用八组怪物美术家族，但通过源点、冲锋、追击、扩散区域和首领阶段区分行为。

## 验证基线

- 10 项核心逻辑测试：角色、关卡覆盖、八种地图差异、路径可达、碰撞、技能、装备、首领前置、任务顺序和资源清理。
- 288 组确定性模拟：轻松难度 96/96、标准难度 96/96 可通关；进阶难度允许正常失败，但不得死锁。
- PWA 检查：清单、图标、仓库相对路径、离线资源和导航回退。
- 静态导出检查：入口页面、资源子路径和 GitHub Pages 构建结果。

测试只能证明已覆盖场景中的行为，不能承诺所有手机型号绝对没有缺陷。正式推广前仍建议补充真实 iPhone、Android 多点触控和弱网测试。

## 内容边界

游戏中的怪物、脉冲、生命值和技能均为虚构模拟。源头控制、隔离、撤离和应急处置为教学抽象，不替代现场风险评估、作业许可、专业授权、操作规程或岗位培训。
