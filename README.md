# 安全边界 · 风险连连看

面向手机与电脑浏览器的 HSE 语义连连看游戏。玩家可选择马·安禾、猫头鹰·永勋、雪豹·凌曜或边牧·观微，通过不超过两个转弯的连接路线，将事故线索、危险状态、控制措施和复核要求组成正确的安全关联。

## 当前版本 3.0

- 12 类现场、36 个关卡，其中工程施工场景 8 类，占场景总数三分之二。
- 工程施工覆盖高层建筑、市政管网、工业安装、停工检维修、临时用电、道路桥梁、拆除改造和深基坑。
- 生产运营覆盖水处理、仓储物流、化学品储运和地下矿山。
- 6×6 连连看棋盘，支持直连、一折和两折路径。
- 每个场景 8 组专业语义配对，并设置位移、遮蔽、压力和能量锁定等现场事件。
- 四名角色拥有不同辅助技能，但不会改变安全规则或形成风险免疫。
- 三档节奏、三星评价、连续正确配对、本机成绩保存。
- 12 套原创程序化声景，随场景、时间和连击变化。
- 手机竖屏、横屏及桌面布局，PWA 离线回访和 Capacitor APK。

## 在线使用

仓库启用 GitHub Pages 后，推送到 `main` 分支会自动测试、构建和发布：

`https://yuyao19.github.io/hse-safety-frontier/`

Android Chrome 可选择“安装应用”或“添加到主屏幕”。iPhone / iPad 可使用 Safari 的“分享 → 添加到主屏幕”。

## 本地运行与检查

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

完整检查：

```bash
npm test
```

静态成品输出到 `out/`：

```bash
npm run build
```

## Android APK

推送到 `main` 后，`Build Android APK` 工作流会测试游戏、生成离线网页资源、同步 Capacitor 工程并构建体验签名 APK：

`HSE-Risk-Link-v3.0.0-android-test.apk`

该体验签名版适合内部测试和直接转发。正式上架应用商店前，应另行创建并妥善保管 release 签名密钥，不得将密钥或密码提交到公开仓库。

## 内容边界

游戏中的连接、角色技能、倒计时和场景事件均为教学抽象。具体控制措施应结合现场风险评估、专项方案、作业许可、操作规程、专业授权和应急预案确定；游戏不能作为岗位胜任证明或现场操作依据。
